# VoiceDesk

Gemini를 이용한 음성 전사, 화자 구분, 한국어 번역 및 SRT 자막 저장용 Windows Python 프로그램입니다.

## 개인용 웹 자막 편집기

추가 패키지 없이 저장소 폴더에서 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory web
```

Windows에서는 `python3` 대신 `py`를 사용해도 됩니다. 같은 컴퓨터의 브라우저에서 `http://127.0.0.1:8765`를 엽니다. 외부 배포나 로그인 없이 사용하는 정적 웹 앱입니다. 영상·음성과 자막은 서버로 업로드하지 않고 브라우저에서 처리합니다. 실행 중인 HTTP 서버는 종료할 때 Ctrl+C를 누르세요.

1. **영상·음성 열기**로 브라우저에서 재생 가능한 파일을 선택합니다.
2. **불러오기**로 기존 SRT나 VoiceDesk 프로젝트(JSON)를 열거나 **자막 추가**로 직접 작성합니다.
3. 자막을 선택해 시작·종료 시간, 화자, 내용을 수정하고 **수정 적용**을 누릅니다. **현재 시점으로** 버튼으로 재생 위치를 시작·종료 시간에 반영할 수 있습니다.
4. 겹쳐 말하는 부분은 **같은 구간에 화자 추가**로 추가한 뒤, 각 화자의 실제 시작·종료 시간을 독립적으로 조정합니다. **겹친 발화만** 필터로 집중 검수합니다. 타임라인 블록은 클릭으로 선택하며 시간 조정은 입력칸에서 합니다.
5. **SRT 내보내기**로 저장합니다. 동시 발화는 시작·종료 경계마다 구간을 나누고 `[화자] 대사`를 여러 줄로 함께 표시합니다. SRT 플레이어의 고정 위치·색상은 보장하지 않습니다.

**배리어프리 편집:** 자막 유형에서 발화, 웃음·비언어 발성, 효과음·환경음, 음악을 선택합니다. 소리 자막은 `웃음`, `문 닫히는 소리`, `잔잔한 음악`처럼 설명만 입력하면 `[웃음]` 등의 대괄호가 자동으로 붙습니다. 소리의 주체가 확실한 경우에만 화자를 지정합니다. 대사와 소리의 시간을 각각 입력하면 동시에 표시·저장되며, 소리 자막도 `겹친 구간만` 필터에 포함됩니다.

`선택 구간 듣기`로 원음과 대조한 뒤 `원음 대조 검수 완료`를 체크하고 적용하세요. 시간·화자·내용·유형을 다시 수정하면 검수 체크가 해제됩니다. 검수 패널은 미검수 개수, 빈 내용, 3줄 이상 동시 표시 구간을 안내합니다. 미검수나 줄 수 경고가 있으면 초안으로 저장할지 확인하며, 실제 내용을 자동 삭제하거나 시간 이동하지 않습니다. 두 줄 안내는 가독성 검수용 기준이며 특정 기관의 표준을 인증하는 기능은 아닙니다. 정확한 싱크, 고유명사, 짧은 반응 누락은 사람이 확인해야 합니다. `[알아들을 수 없는 말]`처럼 불확실한 발화를 명시하고 추측해서 채우지 마세요.

일반 SRT에는 소리 유형·검수 상태 메타데이터가 없습니다. 이 편집기가 내보낸 대괄호 설명을 다시 불러올 때 유형을 추정하므로 확인하세요. 프로젝트(JSON)는 정확한 유형과 검수 상태를 보존합니다. 자동 소리 감지나 인증된 배리어프리 자동 제작 기능은 제공하지 않습니다.

편집 상태는 이 브라우저의 로컬 저장소에 자동 저장됩니다. **프로젝트 저장**으로 JSON을 별도 보관하면 화자별 발화의 원래 구간을 유지할 수 있습니다. 영상 파일은 프로젝트에 포함되지 않으므로 다음에 다시 선택하세요. SRT를 다시 불러오면 화자별 줄은 복원하지만 내보내기 과정에서 나눈 구간은 나뉜 채 유지됩니다. 시크릿 모드나 브라우저 데이터 삭제 시 자동 저장본이 없어질 수 있으므로 프로젝트 파일을 보관하세요. 프로젝트 하나에 미디어 파일 하나를 기준으로 편집합니다.

**현재 웹 버전은 수동 편집·검수 도구입니다.** 자동 전사, 자동 화자 식별, 겹친 목소리의 음성 분리, 파형 분석, 영상 렌더링은 아직 연결하지 않았습니다. 기존 Python 앱의 전사 결과를 SRT로 저장한 뒤 웹 편집기로 불러올 수 있습니다. **예제 살펴보기**는 실제 음성이 없는 가상 대사입니다.

웹 자막 처리 테스트: `node web/subtitles.test.cjs` (Node.js 필요, 추가 패키지 불필요).

## SRT 자막 저장

전사가 끝나면 **자막 저장 (SRT)** 버튼으로 저장합니다. 한국어 번역이 있으면 번역을, 없으면 원문을 사용하고 `[화자 1]`처럼 화자를 표시합니다. 여러 음성 파일을 처리했으면 파일마다 저장 창이 열립니다. 저장을 취소해도 앞서 저장한 파일은 유지됩니다.

동시에 말하는 구간은 화자별 대사를 여러 줄로 함께 표시하며, 각 발화가 시작하거나 끝나는 시점마다 자막을 나눕니다. SRT는 고정 위치나 화자별 색상을 보장하지 않습니다. 이 기능은 전사 결과의 겹치는 시간을 보존하는 것으로, 음성 분리나 오버랩 인식 정확도를 보장하지는 않습니다. 자동 생성한 내용과 시간을 원음과 비교해 검수하세요.

시간은 `00:01.200 - 00:03.450` 또는 `00:00:01,200 - 00:00:03,450` 형식을 지원합니다. 잘못된 시간이나 종료가 시작보다 늦지 않은 구간은 저장 전에 오류로 알립니다.

SRT 변환 검증: `.venv`의 Python으로 `python -m unittest -v test_srt`를 실행합니다.

## 집 컴퓨터에서 실행

Python 3를 설치한 뒤 이 저장소를 내려받고, 프로젝트 폴더의 PowerShell에서 실행합니다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:GEMINI_API_KEY = "본인의 Gemini API 키"
.\.venv\Scripts\python.exe VoiceDesk.py
```

키는 GitHub에 올리지 않습니다. 환경 변수는 위 명령을 실행한 PowerShell 창에서만 유지됩니다. 음성 파일은 Gemini 서비스로 전송됩니다. API 이용 비용과 한도는 본인의 계정 설정에 따릅니다.

## 회사와 집에서 이어서 작업

처음에는 각 컴퓨터에서 이 저장소를 복제합니다.

```powershell
git clone https://github.com/juhyun467/VoiceDesk.git
cd VoiceDesk
```

작업을 시작할 때는 `git pull`, 작업을 마칠 때는 다음 명령으로 저장합니다.

```powershell
git add VoiceDesk.py README.md requirements.txt .gitignore
git commit -m "작업 내용 설명"
git push
```

두 컴퓨터 모두 같은 저장소를 복제한 폴더에서 작업합니다. GitHub는 자동 저장이 아니므로 작업 후 올리고, 다른 컴퓨터에서 시작하기 전에 최신 내용을 받습니다. 각 컴퓨터의 작업을 올린 뒤 컴퓨터를 바꿉니다.

## 저장 범위

기존 outputs 폴더의 VoiceDesk.py를 기준으로 저장했습니다. 코드에 직접 들어 있던 API 키를 환경 변수로 분리했습니다. 기존 실행 파일과 원본 안내 문서는 이 Python 코드와 기능 설명이 달라 포함하지 않았습니다. 실행 파일, 음성 파일, 전사 결과 및 접속 키는 저장소에 포함하지 않습니다.
회사와 집에서 이 저장소로 작업합니다.
